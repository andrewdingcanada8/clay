## Where it stands
- Composite settled 52-60 ms (quiet run 52), from 98. Strict IoU on all six; strict diff on five; grazing diff 2.35 % (aa-tolerant 0.36 %).
- Lessons: SwiftShader parallelizes a draw by quad rows (keep lists narrow); it pays for code that never runs
  (compile it out with defines, don't branch round it); shading from a baked normal/occlusion atlas costs one read.
- Next: grazing's strict diff (normals from the shading atlas at thin slabs and rim creases: aa diff went 0.10 -> 0.35 %);
